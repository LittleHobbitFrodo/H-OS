# markdown
## headings
- ```
  # heading1
  ## heading 2
  ### heading 3
  ...
## linebreaks
- ```
  line followed by 2 spaces

## code blocks
- ````
  `inline` block
- ```
  ``` normal code block```
  
## lists
- unordered ((-, + or *) + space)
  ```
  - item
  + item
  * item
- ordered ((number). + space)
  ```
  1. item 1
  2. item 2
  3. item 3
- nested lists
  ```
  1. first item
    - nested item
      + nested item
  2. second item

## links
- link
  ```
  [text](url)
- reference link (unsupported by MDC)
  ```
  [google][1]
  [1]: url

## block quote
- '>' symbol
  ```
  > quote

## horizontal line
  - (---, ***, ___)
  ```
  ***
